### このツールの目的
最高品質・最先端のWeb小説カルチャーに適応した執筆アプリを無料で。
「さっかのアメ」は豊富な補助機能で、web小説を一つレベルアップさせます
オフライン版はフロントエンドのみで動作するため、非常に手軽に扱え、AIに学習される恐れもありません

##  機能一覧
- 複数の作品、それぞれのシーンやキャラクターを登録・管理
- 作品ごとに「ゴール」「テーマ」を設定
- 各シーンに登場キャラを登録
- 各キャラの登場シーンまとめ
- 全シーンをテキストとしてクリップボードにコピー
- 伏線の可視化、状態管理

##  技術スタック
- フロントエンド | Vue 3 , TypeScript 
- バックエンド | TypeScript （オンライン版） 
- ビルドツール | Vite 
- データベース | IndexedDB 、D1（オンライン版）
- ホスティング | Cloudflare Pages

## 制作環境
- 開発者:個人開発
- 開発期間：6週間程度
- 開発の動機:自分自身が設定管理に頭を悩ませた経験や、追いかけていた作品の更新が止まった経験から
